# План пункта 32: карточка элемента (05.11.2026)

Анализ: агент Opus / high, ключевые строки сверены вручную. Исполнитель: sol / high.

## Модель
`S.unitEdits={ключ:{note?,nm?,w?,d?}}`: поля нет, пока нет значений, пустая запись удаляется. Ключ единицы: `b:<id>:<i>`, `h:x_<uid>:<i>`. У вставок ключи выдаются заново, поэтому комментарий в `i.note`.

## Шаги
1. Комментарий: поле в панели и карточке телефона, спецификация, сведения по помещению, копия сметы, файл проекта, комментарии без элемента.
2. Размер нейтрального: ширина 300–3000 мм, глубина 600/700/800; другой размер закупаемого идёт отдельной позицией по цене каталога с возможностью вписать свою.
3. Назначение: смена внутри семейства каталога (столы, ванны).

## Решения по открытым вопросам (по предложениям плана)
1. Колонка комментария условная также в сведениях по помещению: их читают сантехник, вентиляция, газовая служба.
2. Цена нестандартного размера: цена каталога, можно вписать свою.
3. `lineDepths` и `alignRun` учитывают холодильные шкафы, что расходится с правилом глубины: не менять, отдельный вопрос пользователю.
4. Набор назначений: всё семейство каталога.
