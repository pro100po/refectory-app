# Состояние проекта «Кухня трапезной»

Обновлено: 10 ноября 2026 года, Москва.

## Цель текущего пункта

Перевести рабочий процесс с Claude на настольный Codex: общение с ведущим в чате, отдельные исполнители, понятное наблюдение, проверка результата и безопасное сохранение/публикация.

## Принятые решения

- Ведущий по умолчанию — Astra / medium; пользователь выбирает модель текущего чата. Помощники назначаются по сложности и доступности. Запуск помощника не переключает модель чата.
- Пользователь согласует цель и план пункта. Его шаги выполняются подряд без повторных вопросов о продолжении.
- Общение идёт в чате. `watch.bat` открывает только окно наблюдения.
- У каждого запуска своё задание, состояние и журналы. Конфликтующие изменения общего рабочего каталога выполняются последовательно.
- Принятый промежуточный шаг сохраняется локально. Завершённый пункт отправляется на GitHub; развёртывание проверяется отдельно.
- Этот файл хранится в отдельной ветке `project-status`. Подробные локальные журналы и незавершённый код приложения сюда не включаются.

## Эксплуатация и открытые вопросы

Пользователь открывает `watch.bat`, когда хочет видеть ход работы; общение с ведущим остаётся в чате. Стадии помощников чата регистрирует ведущий явно. При аварийном прерывании он проверяет оставшиеся процессы и сохраняет подтверждение перед снятием блокировки или повтором. Доступ к обычной Windows-сессии нужен для скрытого запуска и проверки процессов; ограничения Codex workspace-write сохраняются.

Открытых вопросов, требующих решения пользователя по текущей миграции, нет. Следующее действие — проверить отправку main и развёртывание, затем зафиксировать итог здесь.
