# Пункт аудита 30.2, недоработка Б: «Уступ на стене» — ступенчатые помещения
Исполнитель: sol / high

Цель: в разделе «Форма» боковой панели помещения появляется действие «Уступ на стене»: стена разбивается в выбранном месте, одна её часть утапливается внутрь помещения на заданную глубину. Повторяя действие, можно получить «лесенку», Z-форму и т. п.

Правки — только в `index.html`.

## 1. Слой стен: функция `stepRoomWall(room, id, off, h, far)`
Добавить рядом с `setRoomShape` (после неё). Возвращает `{ok:true, moved}` или `{error:'…'}`; при ошибке помещение не меняется.

- `id` — id стены, `off` — место уступа в отсчёте `off` этой стены (от угла, который называет `wallFrom(room,id)`, как у проёмов), `h` — глубина внутрь (м), `far` — `true`: утопить дальнюю от угла отсчёта часть, `false`: ближнюю.
- Вершины: как в `wallDragStart` — `P = roomPoly(room).map((q,i)=>({...q, wid:q.wid||walls[i].id}))`, где `walls=roomWalls(room)`; стена `w` с индексом `i` идёт от `a=P[i]` к `b=P[(i+1)%n]`, `u=w.dir`, нормаль внутрь `nv={x:w.nx,y:w.ny}`.
- Точка разрыва: `t = w.offFrom==='start' ? off : w.len-off` (расстояние от `a`), `s = a + u·t`. Требовать `0.3 <= t <= w.len-0.3`, иначе ошибка «Уступ слишком близко к углу — от угла не меньше 300 мм».
- Какая часть утапливается: «дальняя» = хвост `s..b`, если `w.offFrom==='start'`, иначе голова `a..s`; `far===false` — наоборот.
  - хвост внутрь: вместо `a, b` получить `a, s, s+nv·h, b+nv·h` (у `s` — без `wid`, у `s+nv·h` — без `wid`, вершина `b+nv·h` сохраняет `wid` вершины `b`);
  - голова внутрь: `a+nv·h` (**без `wid`** — утопленная голова — новая стена), `s+nv·h` (без `wid`), `s` (у вершины `s` `wid = w.id`: неподвижная часть `s..b` сохраняет id стены `w`), затем `b`.
  - В варианте «хвост» стена от `a` до `s` сохраняет `wid` стены `w` (вершина `a` уже его несёт).
  - Соседняя стена со стороны сдвигаемого конца должна быть перпендикулярна `w`; если нет (`|u·dir соседа| > 1e-9`) — ошибка «Уступ рядом с косой стеной пока не поддерживается».
  - Массив вершин — всегда новый; `room.poly` на месте не менять (кэш стен сравнивает ссылку `room.poly`).
- Проверки до изменений:
  - `shapeError(normPoly(pts, pts.map(p=>p.wid||null)).pts)` — при ошибке вернуть `{error:'Уступ не помещается: '+текст}`;
  - точка разрыва внутри проёма (`room.openings` с `side===id`, интервал `(o.off, o.off+o.w)`) или вытяжки (`room.points` с `type==='hood'`, `(p.off, p.off+p.w)`) — ошибка «Уступ приходится на „<opName(o) или Зонт>“ — сдвиньте место уступа». Точку без ширины на самом месте разрыва (|p.off-off|<1e-6) тоже считать помехой.
- Перенос объектов с утапливаемой части: до изменения для каждого проёма и точки на стене `id`, лежащих целиком на утапливаемой части, запомнить точку `q = wallPoint(room, id, o.off)` (для точек — `p.off`) и ширину. Затем `const r=setRoomShape(room,{tpl:'custom',pts})`. Найти новую стену Y: направление совпадает с `u`, на её отрезке лежит точка `s + nv·h + u·(±0.01)` (знак — в сторону утопленной части). Каждому запомненному объекту: `side=Y.id`, `off=projectToWall(room,Y.id,q.x+nv.x*h,q.y+nv.y*h).off`, вернуть прежнюю ширину; затем `clampRoom({room,openings:room.openings,points:room.points})`. Вернуть `{ok:true, moved:r.moved}`.
- `setRoomShape`, `assignWids`, `shapeError`, `normPoly`, `clampRoom` — не менять.

## 2. Интерфейс: блок «Уступ на стене» в разделе «Форма»
В `shapeSecHtml(r)` после блоков шаблона/поворота/полей и перед `.shp-error-slot` добавить блок (для всех форм, включая прямоугольник):
- заголовок «Уступ на стене»;
- `<select data-step-wall>` — стены `roomWalls(r)`, подпись `wallTitle(r,id)` с заглавной буквы; выбранная — из модульной переменной `let stepWallSel=null;` (если её нет среди стен — первая стена);
- поле «Место уступа, мм — <wallFrom(r,id)>» (`data-step-off`, по умолчанию половина длины выбранной стены, округлить до 10 мм);
- поле «Глубина, мм» (`data-step-depth`, по умолчанию 600);
- переключатель `seg('step-far', …, [['far','Утопить дальнюю часть'],['near','Утопить ближнюю часть']])` (значение — в модульной переменной, по умолчанию `far`);
- кнопка «Добавить уступ» (`data-step-apply`).
Поля сделать через существующий `num(...)` с собственными data-атрибутами. **Не использовать `data-shp-param` и `data-wall-len`** — на них уже висят обработчики, применяющие форму.

В `bindShapeEditor()`:
- смена стены — запомнить `stepWallSel` и перерисовать (`render()`), чтобы обновились подпись «от … угла» и значение по умолчанию;
- переключатель «дальнюю/ближнюю» — запомнить в модульной переменной;
- «Добавить уступ»: прочитать мм (как в существующих обработчиках: убрать пробелы, запятая → точка), проверить место 0…длина стены и глубину ≥ 300 мм (иначе `shapeShowError` у поля), вызвать `stepRoomWall(S.room, id, off/1000, depth/1000, far)`. Ошибка → `shapeShowError(sec, кнопка, error)`. Успех → `lastPush=0; touch(); recompute(); render();` и `toast('Уступ добавлен'+(moved.length?'. '+moved.join('. '):''))`.

Стили — минимальные, в стиле `.shp-controls`/`.shp-fields` (поля в две колонки на компьютере, в одну на телефоне), кнопка 44 px.

## Ожидаемый результат / критерий готовности
1. Пример → «Помещения» → настройки кухни (7200 × 4800) → «Форма» → «Уступ на стене»: верхняя стена, место 3600, глубина 1000, «дальнюю» → контур из 6 стен: правая половина верхней стены опущена на 1000 мм. Окно, стоявшее на правой половине верхней стены (3600…5100), — на опущенной стене, на той же координате по горизонтали, той же ширины.
2. Второй уступ на опущенной стене → «лесенка» из 8 стен; новые стены перетаскиваются на плане (ручки стен).
3. Место уступа посередине окна → ошибка «Уступ приходится на „Окно“ — сдвиньте место уступа», помещение не изменилось.
4. Глубина 4500 на верхней стене → ошибка «Уступ не помещается: …», помещение не изменилось.
5. Ctrl+Z (отмена) возвращает прежнюю форму.
6. Шаги «План», PDF и общий план показывают ступенчатый контур; ошибок в консоли нет.
7. Шаблоны Г, П, Т строятся как раньше.

## Замечания (исправление задания)
Вопрос исполнителя верный: в варианте «голова внутрь» вершина `a+nv·h` должна быть **без `wid`**, а `wid = w.id` — только у вершины `s`. Так стена `a+nv·h → s+nv·h` (утопленная часть) и ступенька `s+nv·h → s` — новые, а неподвижная часть `s → b` сохраняет id `w`; `assignWids()` не трогать. В варианте «хвост внутрь» всё как написано: `a` (с `w.id`), `s` и `s+nv·h` без `wid`, `b+nv·h` с `wid` вершины `b`. Пункт выше исправлен. Выполни задание полностью.
