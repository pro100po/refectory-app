# Пункт аудита 30.2, исправление: стены сложной формы в списках и зонт у внутреннего угла

Цель: у помещений Г-, П-, Т-образной формы стены в списках и полях называются правильно, любую стену контура можно выбрать, зонт не получает отрицательный размер.

Правки — только в `index.html`, только в перечисленных местах.

## 1. Подписи стен вместо «undefined стена»

Сейчас подпись группы берётся из `SIDES[side]` (там только `t`, `r`, `b`, `l`), для стен контура с другими id выходит «undefined стена».

Заменить подпись на название из слоя стен: `wallTitle(S.room, id)` с заглавной первой буквой (например `const t=wallTitle(S.room,side); t[0].toUpperCase()+t.slice(1)`). Для прямоугольника результат совпадёт с прежним («Верхняя стена» и т. д.), для контура будет «Стена 3».

Места:
- `function wallRows()` — заголовок `<h4>${SIDES[side]} стена ...`;
- `function pointRows()` — заголовок `<h4>... ${SIDES[sd]} стена ...` (ветка не для `floor`);
- `function planSheetHtml(u)` — строка `bindTxt=\`${SIDES[pl.s]} стена: от ...` (только название стены; остальной текст строки не менять).

## 2. Список «Стена» / «Где» в настройках проёма и точки

`function roomPanel()`: `const sideOpts=(cur,floor)=>Object.entries(SIDES).map(...)` строит варианты только из четырёх сторон.

Сделать варианты из стен текущего помещения: `roomWalls(S.room).map(w=>w.id)`, подпись — то же название, что в п. 1 (`wallTitle` с заглавной буквы, без добавления слова «стена» — оно уже в названии). Значение `value` — id стены. Выбранной остаётся текущая стена (`cur===id`). Вариант «В полу или на потолке» при `floor` — как сейчас.

Обработчики `[data-of]` и `[data-pf]` (`o.side=el.value`, `setPtSide(p, el.value)`) не менять.

## 3. Зонт у внутреннего угла (`function hoods(s, units)`)

Строка:
```
for(const w of roomWalls(s.room)) if(w.axis && backDist(s.room,w,b)<=0.4){ ...
```
прижимает зонт к любой стене ближе 0,4 м, даже если аппарат стоит не вдоль неё (у внутреннего угла Г-формы получается ширина −1,45 м).

Добавить условие: аппарат стоит вдоль этой стены — проекция `spanOnWall(s.room,w,b)` перекрывает стену: `sp[1]>0 && sp[0]<w.len`. Остальную логику функции не менять.

## Что НЕ трогать
- Словарь `SIDES` и все остальные места, где он используется.
- Слой стен (`roomWalls`, `wallById`, `wallTitle` и т. д.), расстановку, проверки плана, печать.
- Вёрстку и стили.

## Критерий готовности
- Пример → «Помещения» → настройки кухни → «Форма» → «Г». Добавить окно на стену выреза. В разделе «Стены» заголовок группы — «Стена N …», не «undefined стена».
- В настройках этого окна поле «Стена» показывает именно эту стену и содержит все 6 стен; выбор другой стены переносит окно.
- У прямоугольного помещения подписи и списки прежние: «Верхняя стена», «Правая стена» и т. д.
- Шаг «План» с Г-образной кухней: в консоли нет ошибки `<rect> attribute width: A negative value`.
