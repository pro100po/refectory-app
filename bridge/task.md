# Пункт аудита 30.2.2, шаг «План»: одна строка инструментов над планом

Цель: на шаге «План» (функция `stepPlan()`) на экране шире 900 px над планом остаётся одна строка инструментов вместо трёх. На телефоне (до 900 px) всё как сейчас.

Правки — только в `index.html`, только в перечисленных местах.

## Сейчас (1366 px)
1. Строка-ряд кнопок «Изменить стены →» и «Изменить подключения →» (`<div class="plan-tools plan-links" id="pmode-bar">` в `stepPlan()`).
2. Строка слоёв: «Слои · Размеры [Выкл | У выбранного | Все] · Рабочие зоны · Куда вывести сети · Подключения · Подписи» и «Расставить автоматически».
3. Отдельной строкой — масштаб, «Вписать», ⛶ (не поместились).

## Что сделать

### 1. Ссылки — в строку пояснения
В `stepPlan()` убрать блок `<div class="plan-tools plan-links" id="pmode-bar">…</div>`. Вместо него в конец текста пояснения (второй аргумент `stepHead(...)` для `planMode==='equip'`) дописать через пробел:
`<button type="button" class="linkish" data-goto="1">Изменить стены →</button> · <button type="button" class="linkish" data-goto="2">Изменить подключения →</button>`
Класс `.linkish` и обработчик `main.querySelectorAll('[data-goto]')…go(+b.dataset.goto)` уже есть — не менять.
Строку `segBind(document.getElementById('pmode-bar'),…)` удалить: элемента больше нет (режим `planMode` на этом шаге всегда `'equip'`), иначе `segBind(null,…)` упадёт.
Стили `.plan-links` оставить как есть.

### 2. Слои шага «План» — в выпадающее меню на компьютере
В `function layersBarHtml(mode)` только для `mode==='equip'` обернуть содержимое так:
```
<div class="lay-menu [open]" data-fs="plan">
  <button type="button" class="btn lay-tgl" aria-expanded="true|false" aria-controls="lay-pop">Слои ▾</button>
  <div class="plan-layers lay-pop" id="lay-pop" role="group" aria-label="Слои плана">…текущее содержимое (подпись «Слои», «Размеры», кнопки)…</div>
</div>
```
Для `mode` `'room'` и `'points'` разметку не менять.

Состояние открытия — переменная `let layMenuOpen=false;` рядом с `layersBarHtml`. Класс `open` и `aria-expanded` берутся из неё при отрисовке, поэтому меню не закрывается, когда переключение слоя вызывает `render()`.

Поведение (добавить один обработчик рядом с обработчиком `main.addEventListener('click', …)` для `[data-layer]`):
- нажатие на `.lay-tgl` — `layMenuOpen=!layMenuOpen`, переключить класс `open` у `.lay-menu` и `aria-expanded`, без `render()`;
- нажатие мимо `.lay-menu` при открытом меню — закрыть (`layMenuOpen=false`, снять класс);
- `Esc` при открытом меню — закрыть и вернуть фокус на `.lay-tgl` (не мешать существующей обработке `Esc` на плане: если меню закрыто — ничего не делать);
- `go(i)` (смена шага) — `layMenuOpen=false`.

Стили (рядом с `.plan-layers…`):
- `@media (min-width:900px)`: `.lay-menu{position:relative}`; `.lay-pop` скрыт (`display:none`), при `.lay-menu.open .lay-pop` — `display:flex`, `position:absolute; top:calc(100% + 6px); left:0; z-index:20; flex-direction:column; align-items:flex-start; gap:6px; padding:10px; background:var(--sheet); border:1px solid var(--rule); border-radius:10px; box-shadow:0 8px 24px rgba(0,0,0,.14); min-width:max-content`. Кнопки слоёв внутри — как сейчас.
- `@media (max-width:899px)`: `.lay-tgl{display:none}`, `.lay-pop` — как сейчас обычная строка `.plan-layers` (ничего не меняется).
- В режиме «план на весь экран» (`.pfs-head`) меню работает так же (оно переносится вместе с элементами `data-fs="plan"`); если выпадающая панель обрезается — `.pfs-head{overflow:visible}` для неё.

### 3. Строка инструментов
Итог на 1366 px: `[Слои ▾] [Расставить автоматически] [Собрать тепловое под один зонт — если есть]` … справа `[− 100 % +] [Вписать] [⛶]` — одной строкой. Если для этого нужно — уменьшить промежутки, но не размеры кнопок (высота 44 px остаётся).

## Критерий готовности

## Замечания (повтор, правки из первого прохода сохранить)

1. **Телефон (390 px): кнопка «Слои ▾» видна.** Правило `@media (max-width:899px){ .lay-tgl{display:none} }` перебивается более специфичным правилом для `.btn` (вычисленный `display` — `inline-flex`). Поднять специфичность, например `.plan-bar .lay-menu>.lay-tgl{display:none}` (и для режима полного экрана — `.lay-menu>.lay-tgl` внутри `.pfs-head` в той же media). Проверка: на 390 px `getComputedStyle(document.querySelector('.lay-tgl')).display === 'none'`, слои — обычной строкой, как до правки.
2. **Компьютер: в выпадающей панели повторяется подпись «Слои»** (над «Размеры»). При `min-width:900px` скрыть `.lay-pop>.lbl` (на телефоне подпись остаётся).

Больше ничего не менять.
