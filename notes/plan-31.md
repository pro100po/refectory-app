# План пункта 31: препятствия, выступ и ниша в расстановке (05.11.2026)

Анализ: агент Opus / high (сессия на medium), ключевые места сверены вручную: `flowInGeom` (`occ`), `geomHelpers.free`, `hitX/gapX/rectX`, `roomGeom`, `mirrorRoom`, запись `{b,f:NOF}`.

## Модель
`room.obstacles=[{id,kind:'column'|'stove'|'box'|'stair'|'other',shape:'rect'|'round',x,y,w,d,name?}]` — метры, координаты помещения, левый верхний угол габарита; у круга `w=d`.
- Поля нет, пока нет препятствий: `S.rooms` входит в подпись расстановки, пустой массив пересобрал бы старые планы. Чтение — только через `roomObs(room)`.
- `'flow3'` в подписи не менять. Миграции нет.
- `roomGeom` и `mirrorRoom` собирают копию помещения по списку полей: добавить туда (в зеркале `x→W-x-w`), только если непусто.
- Адаптер `obsShapes(room)` → `{x,y,w,h,ob}`, у круга ещё `a:true,P,FP` (выпуклый многоугольник).

## Порядок (отличается от отчёта агента)
Логика идёт раньше интерфейса: без кнопки препятствий нет, поэтому публикация шага 1 ничего не меняет у коллег. В отчёте агента сначала шёл интерфейс, и его нельзя было опубликовать отдельно.

1. Данные, проверки и расстановка (sol / high). `flowInGeom`: затравка `occ` записями `{b,f:NOF,hot:false,cold:false,P?,FP?}`; `bands`; `blocks` в `fillGaps`; `checkUnit`: цикл по `obsShapes` теми же `hitX/gapX`; проверка щита; `snapPos`. Проверка — через `page.evaluate`.
2. Интерфейс и отрисовка (sol / medium). Раздел «Препятствия» на шаге «Помещения», добавление, перетаскивание, размеры, привязки; `planSvg`, `printPlanSvg`, `printOverviewSvg`, отчёт; сдвиг при перетаскивании стены.
3. Слив и привязки выбранного аппарата (sol / high). `sewerRoute`, `frontGap`, `alongRange`, `equipChains`.
4. Выступ в расстановке (sol / high). `posAt`, `packForward`.
5. Ниша (astra / high или sol / high по итогам шага 4). `nicheFit`, вызовы `rectInRoom`, `packForward`, ручное перетаскивание.

## Эталон регрессии (снять до шага 1)
`layoutAll` и `checkLayout` в JSON: пример, Г/П/Т ×4, трапеция, выступ, ниша, щит, два помещения. Шаги 1–3: без препятствий побайтно то же. Шаги 4–5: то же для помещений без выступа и ниши. Обязателен тест асимметричной колонны при зеркале `dir=-1`. Замер времени авторасстановки с круглым препятствием.

## Предложения по открытым вопросам (ждут ответа пользователя)
1. Сохранённые планы не трогаем; новое правило для выступа и ниши действует при следующей пересборке.
2. Препятствие без поворота, только по осям.
3. Вдоль препятствия оборудование спиной не ставится. Короб, вдоль которого нужно ставить, задаётся выступом.
4. В нишу идёт следующее по потоку, что влезает целиком.
5. Препятствие считается до потолка: настенное над ним не ставится.
