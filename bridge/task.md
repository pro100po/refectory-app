# Пункт аудита 30.2.2, шаг «Подключения»: компактная шапка над планом

Цель: на шаге «Подключения» (`stepPoints()`, план рисует `roomEditor()`) на экране шире 900 px над планом две строки инструментов вместо четырёх блоков. На телефоне (до 900 px) всё как сейчас.

Правки — только в `index.html`, только в перечисленных местах.

## Сейчас (1366 px), сверху вниз
1. Пояснение `stepHead('Точки подключения', …)` — три строки.
2. Панель `<section class="panel nets-panel">` с переключателем `seg('utilities', …)` «Сети уже есть — отмечу их на плане / Сетей пока нет — проектируем» и подсказкой под ним (в режиме «проектируем» ещё `notesHtml([{t:'info', m:NETS_INFO}])`).
3. Палитра точек `.pt-pal` (в `roomEditor()`, переменная `tools`).
4. Слои `layersBarHtml('points')` и масштаб `zoomCtl()`.

## Что должно получиться (≥ 900 px)
```
Точки подключения | Отметьте, что уже есть: вода, канализация, газ, вентиляция, электрощит. Точки привязываются размерами от углов.
Сети: [Уже есть | Проектируем]                              [Слои ▾] [− 100 % +] [Вписать] [⛶]
[ХВ Холодная] [ГВ Горячая] [К Канализация] [В Вентканал] [Г1 Газ] [ЩР Щит] [ЭЛ Эл] [+ Зонт]
(в режиме «Проектируем» — строка-справка NETS_INFO, как сейчас)
план
```

## Что сделать

1. **Пояснение.** Текст второго аргумента `stepHead('Точки подключения', …)` заменить на: «Отметьте, что уже есть: вода, канализация, газ, вентиляция, электрощит. Точки привязываются размерами от углов.»

2. **Переключатель сетей в строке инструментов.** В `roomEditor()` при `step===2` первой строкой `.plan-bar` вывести слева блок
   `<div class="nets-inline"><span class="lbl">Сети:</span>${seg('utilities', <то же значение>, [['existing','Уже есть'],['design','Проектируем']])}</div>`
   с `title` у блока — прежний текст подсказки для текущего режима (тот, что сейчас в `<p class="hint">` под переключателем). Справа в той же строке — `layersBarHtml('points')` и `zoomCtl()`.
   Палитру `tools` перенести во вторую строку: отдельный `<div class="pt-pal-row">${tools}</div>` сразу после `.plan-bar` (до подсказки `hint` режима добавления).
   В режиме «Проектируем» сразу после палитры — `notesHtml([{t:'info', m:NETS_INFO}])` (только на ≥ 900 px; на телефоне справка остаётся в прежней панели).
   Существующая привязка `segBind(main,(k,v)=>{ if(k!=='utilities') …})` должна работать для обоих переключателей без изменений.

3. **Телефон без изменений.** Прежнюю `<section class="panel nets-panel">` в `stepPoints()` оставить, но показывать только при `max-width:899px`; новый блок `.nets-inline` (и справку после палитры) — только при `min-width:900px`. На телефоне порядок элементов в `roomEditor()` должен остаться прежним: палитра, затем слои и масштаб (при необходимости — через `order` в CSS для `max-width:899px`).

4. **Слои ▾ и здесь.** В `layersBarHtml(mode)` выпадающее меню `.lay-menu` (сделано для `mode==='equip'`) включить также для `mode==='points'`. Обработчик `handleLayMenu`, стили `.lay-menu`/`.lay-pop`/`.lay-tgl` и сброс `layMenuOpen` в `go()` уже есть — не менять, только условие.

5. **Стили** (рядом с `.nets-panel …`): `.nets-inline{display:flex;align-items:center;gap:8px}` , `.nets-inline .seg button{min-height:44px;white-space:nowrap}`, `.pt-pal-row{margin-bottom:10px}`; в `.plan-bar` блок `.zbar` остаётся прижатым вправо (`margin-left:auto` у первого справа элемента — слоёв).

## Что НЕ трогать
- Шаги «Помещения» и «План», `layersBarHtml('room')`.
- Логику палитры, `fitPal()`, режимы добавления точек, панель настроек точки, «Точки и привязки», «Проверка точек», «Ресурсы по плану».
- Тексты подсказок и NETS_INFO (только перенос).

- 390 px: вид как до правки (панель сетей, палитра, слои строкой, масштаб; кнопки «Слои ▾» нет).
- Ошибок в консоли нет.
