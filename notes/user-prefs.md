# Пожелания пользователя к работе Claude

- (04.11.2026) Перед каждым запуском задания GPT — показывать пользователю **ожидаемый результат выполнения**: что изменится на экране / в расчётах и как это будет проверено. Сейчас и в будущем.
- Пользователь не хочет быть «прокси» между облаком и компьютером: задания из облака идут через мост (см. раздел в CLAUDE.md).
- (04.11.2026) Согласованный пункт, разбитый на подпункты (шаги), — выполнять подряд по плану без согласования перед каждым шагом; открытые вопросы плана решать по своему предложению и сообщать выбор; ожидаемый результат показывать, но ответа не ждать. Спрашивать — только при существенном изменении плана. (Правило дописано в CLAUDE.md.)
- (05.11.2026) Уточнение, пользователю надоели подтверждения: внутри пункта с шагами вопросов «продолжаем?» нет совсем, в том числе после прерванной команды. Спрашивать и предлагать варианты — только при новых вводных. (CLAUDE.md, раздел «Пункт, разбитый на шаги».)
