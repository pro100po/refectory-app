# Пункт аудита 30.2.2, шаг «Помещения»: «Слои ▾» и одна строка инструментов при открытой боковой панели
Исполнитель: sol / medium

Цель: на шаге «Помещения» (`stepRoom()`) на экране шире 900 px строка над планом не переносится — и без боковой панели, и с открытой панелью настроек помещения (1366 px). На телефоне (до 900 px) всё как сейчас.

Правки — только в `index.html`, только в перечисленных местах.

## Сейчас
`stepRoom()` выводит `<div class="plan-bar">${layersBarHtml('room')}<div class="plan-bar-actions">…+ Дверь, + Окно, + Выступ / ниша, (Расставить по связям), + Помещение…</div>${zoomCtl()}</div>`.
Слои для `mode==='room'` — строкой («Слои · Размеры · Подключения · Подписи»). При открытой боковой панели (`rpOpen`, ширина основной колонки уменьшается на ~416 px) масштаб, «Вписать» и ⛶ уходят на вторую строку.

## Что сделать
1. В `function layersBarHtml(mode)` выпадающее меню `.lay-menu` (сейчас условие `(mode==='equip'||mode==='points')` в двух местах — открытие и закрытие обёртки) включить и для `mode==='room'`, то есть для всех режимов. Обработчик `handleLayMenu`, стили `.lay-menu/.lay-pop/.lay-tgl`, сброс `layMenuOpen` в `go()` — не менять.
2. Проверить, что на 1366 × 900 с открытой боковой панелью строка помещается: `[Слои ▾] [+ Дверь] [+ Окно] [+ Выступ / ниша] [+ Помещение]` … `[− 100 % +] [Вписать] [⛶]`. Если не помещается — уменьшить только горизонтальные отступы/промежутки в этой строке (правило `@media (min-width:900px){ .plan-bar … }`), высоту кнопок 44 px не менять. Когда помещений больше одного, добавляется «Расставить по связям» — тогда перенос допустим.

## Что НЕ трогать
- Шаги «Подключения» и «План», боковую панель помещения, окно «+ Помещение», план.
- Мобильную вёрстку (до 900 px): там «Слои ▾» скрыта и слои идут строкой — уже обеспечено стилями.

## Ожидаемый результат / критерий готовности
- Пример → «Помещения», 1366 × 900, панель закрыта: одна строка «Слои ▾ · + Дверь · + Окно · + Выступ / ниша · + Помещение … − 100 % + · Вписать · ⛶».
- То же с открытой панелью (нажать на помещение): та же одна строка, масштаб не переносится.
- «Слои ▾» открывает «Размеры», «Подключения», «Подписи»; переключение работает, меню не закрывается; клик мимо или Esc закрывают.
- «+ Дверь» включает режим добавления, «+ Помещение» открывает окно — как раньше.
- 390 px: вид как до правки (кнопки «Слои ▾» нет). Ошибок в консоли нет.
