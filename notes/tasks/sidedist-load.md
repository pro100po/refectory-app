# Ошибка при загрузке: первая перерисовка обрывается из-за `sideDist`
Исполнитель: terra / medium

## Цель
При первой загрузке страницы нет ошибки `Uncaught ReferenceError: sideDist is not defined`.

## Причина
`render()` на последней строке кода второго `<script>` (сразу перед `lastSnap=snap(); updUndo();`) вызывает цепочку `stepIss` → `checkLayout` → `checkUnit` → `unitWallDist` → `sideDist`. `sideDist` и `sideSpan` объявлены в более позднем `<script>` и в этот момент ещё не существуют. Исключение обрывает скрипт, поэтому `lastSnap=snap(); updUndo();` не выполняются при первой загрузке. Ошибка есть с пункта 30.6, шаг 3.

## Что сделать
Перенести объявления целиком, без изменения кода:
```
function sideDist(b,s,room){ return backDist(room,s,b); }
function sideSpan(b,s,room){ return spanOnWall(room,s,b); }
```
из их нынешнего места в первый `<script>`, сразу перед `function unitWallDist`.

Затем проверить: нет ли в цепочке первой перерисовки других функций из более поздних `<script>`. Если следующая такая ошибка появится при загрузке, не исправляй её: опиши её в отчёте.

## Что НЕ трогать
Логику `unitWallDist`, `unitWallSpan`, `backDist`, `spanOnWall`, порядок скриптов, вызов `render()`. Только перенос двух строк. Без переформатирования.

## Критерий готовности
1. Открыть страницу с сохранённым проектом, где расставлено оборудование, и с новым проектом: в консоли нет `ReferenceError`.
2. После загрузки `lastSnap` не `undefined`, кнопки отмены в верном состоянии: первая правка отменяется, Ctrl+Z возвращает исходное состояние.
3. `sideDist` и `sideSpan` объявлены ровно по одному разу.
4. `node --check` проходит. Diff — две строки перенесены, других изменений нет.

## Сообщение коммита
Исправлена ошибка при загрузке страницы: первая перерисовка больше не обрывается из-за проверки расстояния до стены
